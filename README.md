# 5-js-mini-projs
5 small JavaScript mini projects made for a uni class. Received full marks

average.js - returns the average of two parameters.

compare.js - compares the value of two parameters. Returns boolean result on whether x and y share value and type.

countunique.js - returns the number of unique entries in an array.

searchbooks.js - returns all books written by a specific author, and the list of the book titles.

pushmultiplysum.js - takes a numeric array and an extra number as input; extends array with the extra element, doubles each element of the extended array then returns the sum of all values in updated array.
